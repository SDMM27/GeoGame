
# GeoGame

## Description

Ce projet est une application React créée pour jouer à des minis-jeux de géographie. Ce README fournit des instructions pour cloner le projet, installer les dépendances et lancer l'application en mode développement.

## Prérequis

Assurez-vous d'avoir installé les éléments suivants sur votre machine :

- [Node.js](https://nodejs.org/) (version LTS recommandée)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

## Installation

1. **Cloner le dépôt**

   ```sh
   git clone https://github.com/votre-utilisateur/votre-repo.git](https://github.com/SDMM27/GeoGame.git)
   ```

2. **Accéder au répertoire du projet**

   ```sh
   cd votre-repo
   ```

3. **Installer les dépendances**

   Avec npm :

   ```sh
   npm install
   ```

   Ou avec yarn :

   ```sh
   yarn install
   ```

## Utilisation

### Développement

Pour lancer l'application en mode développement, utilisez l'une des commandes suivantes :

Avec npm :

```sh
npm start
```

Ou avec yarn :

```sh
yarn start
```

L'application sera accessible à l'adresse [http://localhost:3000](http://localhost:3000).

### Construction pour la production

Pour créer une version optimisée de l'application pour la production :

Avec npm :

```sh
npm run build
```

Ou avec yarn :

```sh
yarn build
```

Les fichiers optimisés seront créés dans le dossier `build`.

### Tests

Pour lancer les tests :

Avec npm :

```sh
npm test
```

Ou avec yarn :

```sh
yarn test
```
