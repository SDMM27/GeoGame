# i18n FR/RU — Design Spec
**Date:** 2026-04-29

## Objectif
Ajouter un switch de langue Français / Russe au site GeoGame, avec persistance du choix dans localStorage.

## Stack
- `i18next` + `react-i18next`
- Langue par défaut : français (`fr`)
- Persistance : `localStorage` clé `geogame-lang`

## Structure des fichiers
```
src/
  i18n/
    index.js              ← config i18next
    locales/
      fr.json             ← 243 chaînes en français
      ru.json             ← 243 chaînes en russe (générées par IA)
```

## Initialisation
`src/i18n/index.js` est importé en side-effect dans `src/main.jsx` avant le rendu de l'app.

## Organisation des clés
Les clés sont regroupées par domaine dans les JSON :
- `nav.*` — navbar et navigation
- `home.*` — page d'accueil, descriptions des jeux
- `game.*` — UI commune de jeu (valider, suivant, score, etc.)
- `difficulty.*` — Facile, Moyen, Difficile, Impossible, Hardcore
- `modes.*` — Journalier, Infini, Standard, Ascension
- `flags.*` — textes spécifiques au jeu drapeau
- `capitals.*` — textes spécifiques au jeu capitales
- `multiplayer.*` — lobby, salle, config
- `scoreboard.*` — tableau des scores
- `continents.*` — noms des continents
- `errors.*` — messages d'erreur et toasts

## Bouton de switch (NavBar)
- Texte affiché : langue cible (affiche `RU` si on est en FR, `FR` si on est en RU)
- Placement : dans la `NavBar` existante
- Comportement : click → `i18n.changeLanguage()` → localStorage → re-render instantané, pas de rechargement

```jsx
const { i18n } = useTranslation();
const toggleLanguage = () => {
  const next = i18n.language === 'fr' ? 'ru' : 'fr';
  i18n.changeLanguage(next);
  localStorage.setItem('geogame-lang', next);
};
<button onClick={toggleLanguage}>
  {i18n.language === 'fr' ? 'RU' : 'FR'}
</button>
```

## Migration des composants
Chaque composant avec du texte hardcodé :
1. Ajoute `const { t } = useTranslation();`
2. Remplace chaque string par `t('domaine.clé')`

Fichiers concernés : ~30 fichiers JSX dans `src/pages/` et `src/components/`.

## Traductions russes
Générées par IA à partir du `fr.json`, à corriger manuellement si nécessaire.

## Hors scope
- Anglais ou autres langues
- Traduction du contenu des données de jeu (noms de pays, capitales) — ces données sont universelles
- Détection automatique de la langue du navigateur
